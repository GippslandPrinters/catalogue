To add it in Outlook
  1. Click Copy signature above.
  2. Outlook on the web or new Outlook: Settings → Accounts → Signatures. Outlook for Mac: Outlook → Settings → Signatures. Outlook for Windows: File → Options → Mail → Signatures.
  3. Delete your old signature text, paste (Cmd+V or Ctrl+V), and save.
  4. Set it as the default for new messages and replies.

If Copy doesn't work, select everything inside the dashed box with your mouse, copy, then paste.
